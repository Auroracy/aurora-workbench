# aurora-workbench · 微信小程序版

把网页版单文件工作台改写成**微信原生小程序**（不走 web-view，纯 WXML/WXSS/JS）。

## 一、怎么跑起来

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目 → 目录选 **`miniprogram/`**（不是仓库根目录）
3. AppID：先在 `project.config.json` 里把 `"appid": "touristappid"` 换成你自己的小程序 AppID
   （没有也能先用「测试号」或游客模式预览）
4. 点「编译」，即可在模拟器里看到效果；真机用「预览」扫码

> 这是一个纯本地项目：**不联网、不需要服务器域名**，所以发布前只要完成小程序备案即可，
> 不必配 https 域名。

## 二、目录结构

```
miniprogram/
├─ app.js / app.json / app.wxss     全局入口、tabBar、主题变量
├─ project.config.json              开发者工具配置（AppID 在这里改）
├─ utils/
│  ├─ words.js                      词库 100 词 + 释义/例句/搭配（脚本从网页版提取）
│  ├─ store.js                      存储层：替代 localStorage
│  ├─ word.js                       英语模块逻辑层（纯数据函数，无 DOM）
└─ pages/
   ├─ index/                        首页：今日概览 + 数据导入导出
   └─ english/                      每日英语单词（已迁移完整版）
```

## 三、从网页版迁移过来的设计

| 网页版 | 小程序版 |
|---|---|
| `localStorage` 存整份 DB | `wx.getStorageSync/setStorageSync`，**数据结构完全一致** |
| `innerHTML` 拼 HTML 字符串 | 句子预先切成片段数组 `[{t}, {t, blank}]`，WXML 用 `<template>` 遍历渲染 |
| `onclick="fn()"` | `bindtap`（通过 `data-*` 传参） |
| 直接读写 DOM | 全部走 `setData`，`render()` 统一算出一个新 data |
| CSS 变量 + px | 同样的配色变量，px → rpx（1px ≈ 2rpx） |

**渲染的核心转变**：网页版靠 `wqMaskWord` 把原词替换成 `<span class="word-blank">`；
小程序不能注入 HTML，改成 `blankParts()` 返回结构化片段，
由 `tplParts` 模板根据「是否揭示」决定渲染 `________` 还是单词本身。

## 四、已迁移的功能

**每日英语单词**（完整）

- 精练卡片：多义项、常用搭配、例句（主例句挖空 + 该词自己的更多用法带中文）
- 拼写验证：答对/答错反馈，答案会同步揭示例句与搭配里藏起来的词
- 标记：已掌握 / 模糊 / 不认识，再点一次可取消
- **强化复习**：模糊默认需再答对 2 次、不认识 3 次（1~6 可改），
  答错进度回退且排回队尾 → **反复出现直到掌握**；达标自动标记已掌握并出队
- 队列按单词名存储，**可跨天延续**；支持查看队列、单强化某个词
- 等级 / XP / 连击 / 连续天数 / 徽章
- 支持左右切词、切到前一天/后一天的单词

**暂缺**：朗读发音（小程序没有内置 TTS，需接入 https 音频源后再补）。

## 四点五、联网怎么办（个人主体的最优解：云函数中转）

`wx.request` 有三条硬规矩：**必须 https、域名必须 ICP 备案、必须在后台加白名单**，
http / IP / 带端口一律拒绝。所以联网模块不能直接打第三方接口。

但**云函数跑在服务端，不受这套规则约束**，于是有了绕开备案的路径：

```
小程序  --wx.cloud.callFunction-->  云函数 auroraProxy  --https-->  新浪 / 东方财富 / 央视
```

结论：**个人主体不买域名、不做域名备案，也能联网。**

### 启用步骤（约 3 分钟）

1. 开发者工具顶部点「**云开发**」→ 开通 → 创建环境（免费额度个人够用）
2. 环境设置里复制「**环境 ID**」（形如 `aurora-1g8xxxxx`）
3. 把环境 ID 填进 `app.js` 的 `const CLOUD_ENV = ''`
4. 左侧文件树右键 `cloudfunctions/auroraProxy` →
   「**上传并部署：云端安装依赖**」（会装 iconv-lite，用于新浪 GBK 转码）
5. 代码里用 `utils/cloudApi.js` 取数据：
   ```js
   const api = require('../../utils/cloudApi.js');
   api.text('https://hq.sinajs.cn/list=sh000001', 'gbk').then(t => { /* ... */ });
   ```

### 云函数的安全边界

`cloudfunctions/auroraProxy/index.js` 里维护了一份**域名白名单**
（新浪 / 东方财富 / 腾讯行情 / 央视 / 上金所，与网页版 `server.js` 的数据源一致），
不在名单里的 URL 一律拒绝 —— 不会被当成任意转发的中转站。

### 三条路怎么选

| 方案 | 需要什么 | 何时可用 | 适合 |
|---|---|---|---|
| **云函数中转**（推荐） | 开通云开发环境 | 现在就能用 | 个人主体、不想等备案 |
| 域名 + 备案 + HTTPS | 域名 ~50 元/年，备案 7~20 工作日 | 备案下来之后 | 想让网页版和小程序共用一个后端 |
| 手动录入 | 无 | 立即可用 | 只做记录、不需要实时行情 |

## 六、把网页版的数据搬过来

网页版的数据在浏览器 localStorage 里，小程序读不到，需要导一次：

1. 网页版页面 → 打开浏览器控制台 → 执行（key 已确认为 `aurora_workbench_v2`）
   ```js
   copy(localStorage.getItem('aurora_workbench_v2'))
   ```
   命令会自动把整段 JSON 复制到剪贴板（也可在 DevTools 的
   Application → Local Storage 里手动复制该 key 的 value）
2. 小程序首页 → 「数据迁移 · 备份」 → 点「粘贴」（读取剪贴板）→ 选「合并」→ 点「导入」

也可以在小程序首页点「导出（复制）」把数据倒回去。
